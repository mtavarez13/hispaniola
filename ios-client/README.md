# HispaniolaPay para iOS

Cliente nativo SwiftUI conectado al mismo backend, saldo y movimientos de Android y la web.

## Abrir en Xcode

1. Instala Xcode 15 o posterior y XcodeGen en una Mac.
2. Ejecuta `xcodegen generate` dentro de `ios-client`.
3. Abre `HispaniolaPay.xcodeproj`.
4. Selecciona el equipo Apple Developer y un perfil de firma.
5. Compila para un iPhone con iOS 16 o posterior.

La generación de un archivo IPA firmado exige macOS, Xcode y una cuenta Apple Developer.
